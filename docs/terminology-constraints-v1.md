# OPUS领域术语约束：新增查询、关系保真与端到端耗时（2026-10-31）

本轮只用预训练模型推理，没有训练。固定16个新增中文意图、同一40图图库，比较原始OPUS greedy/beam1、无约束beam4、领域词汇约束beam4，分别搭配SigLIP2 Base224和So400m384。每次自动请求重新翻译，生成后不手改英文。

**结论：本配置修正了一部分逆变器术语，但没有成为更可靠的检索路径。** 两模型的约束策略都在6/16意图上触及64-token上限、没有正常EOS，失败率37.5%；这些失败按0留在效果分母。So400m原始中英融合mAP **0.8534**、端到端p50 **119.52ms**；约束融合为 **0.5469 / 535.95ms**。Base对应为 **0.7978 / 100.79ms → 0.4292 / 582.64ms**。本小集不支持将约束设为默认，代码保留为显式实验选项。

## 约束做了什么，没有保证什么

[source-triggered词表](../benchmarks/terminology-constraints-v1/glossary.json)要求microinverter(s)、inverter(s)、变压器语境bushing(s)、cooling fins或radiator fins，允许句首大写。中文最长匹配避免微型词再叠加通用inverter；电缆/线缆套管不强制bushing。英文约束token用Marian的目标SPM编码。

词汇约束只是在近似beam搜索中要求目标子序列出现：

$$
\hat y\approx\arg\max_{y:\,c_k\subseteq y,\ \forall k}\mathrm{score}_{MT}(y,q_{zh}).
$$

这里的包含关系不表达“导线接在哪”“是否可见”“在板下还是板背后”，也不保证词语属于同一设备。上游实现可能返回未满足约束的候选，适配器因此额外核验完整词、token子序列及EOS，失败时拒绝检索。原样失败输出和序列仍保存，未补词、剪掉重复片段或偷偷回退。

Transformers5.22.1的约束搜索来自固定[生成实现](https://huggingface.co/transformers-community/constrained-beam-search/tree/07b2f120b7db38f1d7bac617ad65ea130508f297)，只准备4个代码/README文件，不下载附带Qwen权重。源代码本地核验后作为callable运行；OPUS/SigLIP模型仍关闭远程自定义代码。来源与未声明仓库级许可的边界见[解码来源清单](../benchmarks/terminology-constraints-v1/decoder-provenance.json)，外部代码不重新分发到Git。

**无约束beam4是必要控制。** 直接将beam1与约束beam4比较，会混入搜索宽度变化；因此主要同时看约束相对原始和相对相同beam4的差异。

约束没有比同beam4多保留接线或安装检查点，并有遗漏。三个可见性/缺失检查点中，没有配置完整保留源谓词及对象；保住否定词却换错设备名仍只算部分，故不能靠加名词解决关系。

- **t03否定谓词不对。** 原始、beam4、约束都有`no wires were removed`，源中文是没有接出的电线；“没有拆线”不能表达“未接出线”。即便So400m原始/约束英文AP都为1，也不能据排名证明否定翻译正确。
- **t10导线变保险丝。** 三输出均出现`fuse`，源词是导线；约束还将`Bushing`放到末尾，发生重复并失败。词汇表没有修正这种接线错误。
- **t12前后关系颠倒。** 原始/约束把鳍片放在电缆前，源文要求电缆垂在鳍片前；beam4保留前后关系但遗漏悬垂状态。原始英文两检索模型AP仍为1，进一步说明本图库检索命中不验证句子关系。
- **安装、支撑、指代仍有损失。** 审阅记录了“上方→机身上”“支架→阶梯/升降”“电表→桌子”、左右关系/间隔归属改变等；这是具体文本观察，不是单个词造成AP变化的因果证明。
- **不添加中文没要求的条件。** t01/t09没有要求闭壳，未按备注额外条件扣分。t16“机柜下方”可能指柜外下方或柜内下部，保留源文本/标签，另做敏感性分析。

## 下一步改进，继续不训练

1. **保留原始默认，显式实验选项。** 本集原始OPUS+So400m融合是质量候选，普通beam4融合几乎持平却更慢；约束不设默认。继续用现场新查询验证，旧8意图的推荐不覆盖本轮结果，反之亦然。
2. **先解决完整生成和失败处理。** 在另外开发查询上预先确定重复抑制、预算/beam/约束位置或软约束，再用新留出集验证。不能简单放宽EOS，把未完成片段当成功；也不能只删困难词查询。可设计显式中文或原始翻译回退，但必须记录触发率和先失败再回退的真实总耗时；本轮没有实现/声称回退收益。
3. **约束谓词和对象关系。** bushing/fins的名词包含不足，需要同时检查接线、可见/不可见、同一设备、支撑、前后/上下。固定短语、源槽位保护或结构化重排是候选，不能在本16条上调规则后仍沿用v1成绩。
4. **补人工真值和歧义清理。** 领域人员复核t16字面/意图以及e026同图两设备归属，细化“接线/连接”“鳍片/辐射片”等边界；纠正时另建版本并重评全部配置，原集与所有负结果保留。
5. **评估检索需要的结构信息。** 若译文完整仍把单个柜/一排柜、板下/无板、裸露鳍片/百叶外罩混淆，再做主体与上下文/局部特征实验；不能只裁设备而丢失安装关系。OCR、几何和训练仍属于另立任务。
6. **性能与证据补全。** 多轮交错模型顺序、按真实查询长度和并发测尾延迟/峰值资源，定位CPU候选管理与同步开销；译文缓存miss/hit另测且含配置指纹。以后可保存逐重复输出/排名或摘要，以及在协议中预声明检索权重字节SHA，增加独立可审计性。
