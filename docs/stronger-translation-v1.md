# 更强预训练译者：术语、检索与端到端耗时（2026-10-31）

本轮选择 **NLLB-200 1.3B**，与 OPUS-MT 在同一 40 图 / 8 中文意图上重新对照，分别搭配 SigLIP 2 Base224、So400m384。全程只做预训练模型推理，**没有训练、修改标签、手改译文或按查询调权重**。

**结果是术语改善，但整体检索未超过 OPUS-MT。** NLLB 把三处错误的逆变器译法改为 inverter / microinverter；套管仍译为 tube，散热片译为较宽泛的 heat sink。So400m 自动英文 mAP 从 OPUS 的 **0.9171 降至 0.8104**；融合 **0.8868 / 0.8866** 基本持平。NLLB 的 So400m 自动请求 p50 为 **420.60 / 428.21 ms**，OPUS 为 **70.97 / 78.71 ms**。本集没有支持替换默认译者的效果或时延收益。

## 模型与固定条件

- 更大容量的候选为 [facebook/nllb-200-1.3B](https://huggingface.co/facebook/nllb-200-1.3B)，revision `b0de46b488af0cf31749cd8da5ed3171e11b2309`。模型卡列出 CC-BY-NC-4.0 和研究用途；这里的“更强”是要检验的候选假设，不是已证实的设备翻译或检索优势。
- 对照为 [Helsinki-NLP/opus-mt-zh-en](https://huggingface.co/Helsinki-NLP/opus-mt-zh-en)，revision `cf109095479db38d6df799875e34039d4938aaa6`，CC-BY-4.0。两者官方源权重都在本地转为 safetensors，没有更新参数，保留源/转换 SHA256 与作者 README。
- 检索 checkpoint 与先前一致：Base `75de2d55ec2d0b4efc50b3e9ad70dba96a7b2fa2`；So400m `e8e487298228002f3d8a82e0cd5c8ea9c567f57f`。复用各自固定图像索引，禁止跨模型混用向量。
- 原中文、40 图与 qrels 未变；每译者分别测中文直接 / 自动英文 / 中英融合，融合是同一 SigLIP 空间内两余弦分数各 0.5，未再归一化均值向量。此前助手提供的英文没有传给译者或替换自动输出。
- 解码固定不采样、beam1、最多 64 个新增 token，源上限 256 token，float32 / MPS。NLLB 显式控制 `zho_Hans` 源语言、`eng_Latn` 目标 BOS；两级 generation config 都清理默认长度和强制 EOS 回填，截断、空译文或异常结束报错。
- 每次自动请求都真实翻译，不缓存英文字符串。单次生成内部 KV cache 开启。分别同步后测翻译、检索与真实整次 wall time，不把阶段分位数相加当作总时间。
- 同一实现下依次运行 OPUS-Base → NLLB-Base → OPUS-So400m → NLLB-So400m，四个独立进程，无其他模型并行任务。每个进程中译者与检索模型同时常驻，中文控制组不执行翻译。
- Apple M4 Pro / 24 GiB / macOS 27.2 arm64，Python 3.12.16、PyTorch 2.15.0、Transformers 5.22.1。每组合每策略预热 3 次，再测 8 意图各 10 次，即 80 个热请求 / 策略，共 **960 个计时样本**。加载、哈希验证、首次请求单独记录。

数据、代码、协议、译者全文件、两索引及术语规则在 NLLB 译文和结果出现前已冻结；计时代码 commit 为 `f023fa2`。旧 OPUS 报告保留为历史记录，本次表格全部采用新跑的四组结果，不混入旧耗时。

## 先检查术语，再看检索

术语规则先于 NLLB 输出固定，另一助手只看中文与原样英文完成审阅，未查看检索结果或日志；模型名称没有盲化。共 6 处机会，其中逆变器重复出现 4 处，所以这不是六种独立术语的通用翻译准确率。

| 意图 / 术语 | OPUS 原样片段 | 判定 | NLLB 原样片段 | 判定 |
|---|---|---|---|---|
| i01 微型逆变器 | microreversers | 错义 | solar microinverters | 明确 |
| i02 逆变器 | Solar inverters | 明确 | solar inverters | 明确 |
| i03 逆变器 | solar reverses | 错义 | solar inverter | 明确 |
| i04 逆变器 | Solar reverseers | 错义 | Solar inverters | 明确 |
| i07 电力变压器套管 | a holster | 错义 | a tube | 错义 |
| i07 可见散热片 | radiator | 部分 | a heat sink | 部分 |

明确 / 部分 / 错义 / 遗漏：OPUS **1 / 1 / 4 / 0**，NLLB **4 / 1 / 1 / 0**。NLLB 的 tube 没有绝缘部件或电气套管限定，不满足此领域的 bushing 含义。radiator / heat sink 表达冷却部件，但未明确鳍片形态；本规则针对图中“可见散热片”，仅记部分，不意味着这些词在所有语境都不正确。

术语依据：[Enphase microinverter 产品页](https://enphase.com/store/microinverters/iq8-series/iq8ac-microinverter)；Hitachi Energy 的[中文变压器套管](https://www.hitachienergy.cn/cn/zh/products-and-solutions/insulation-and-components/transformer-insulation-components/transformer-bushings)与[英文 bushing 产品](https://www.hitachienergy.com/us/en/products-and-solutions/insulation-and-components/transformer-insulation-components/transformer-bushings/bushings-product-selection/ac-bushing-type-goe)；[变压器附件手册](https://hitachi.asia/ice/brochures/pdf/transformer_accessories.pdf)印刷页 12 的冷却结构。没有用这些术语约束生成，也没有修正译文后重测。

上下文另行核对：NLLB i05 漏掉“接线”，i06 的“成排”关系也未保留；OPUS i06 虽有 platoon，但没有清楚表达两排柜间通道。两译者 i02 的外壳关闭状态均不够明确。完整原样句子与审阅依据见[译文](../benchmarks/stronger-translation-v1/translations.json)、[术语规则](../benchmarks/stronger-translation-v1/term-review-rules.json)、[独立文本审阅](../benchmarks/stronger-translation-v1/term-review.json)。

- **i03 术语与上下文改善伴随 Base 排名改善。** OPUS 为 “solar reverses”，NLLB 为暴露电路板/蓝色电容的 inverter。Base 首位从 e007 变为真正开壳的 e012，AP 0.3333 → 1.0000；So400m 原本已为 1。这是整句同时变化的观察，未做单词替换消融，不能单独归因于 inverter。
- **i01、i04 表明正确名词不保证检索更好。** i01 NLLB 的 microinverter 正确，但 Base 英文首位变为非微型设备 e008，AP 0.5536 → 0.2778；So400m 则提高到 0.7917。i04 虽修复 inverter，So400m 英文 AP 仍从 1 降至 0.7667，正例位置变为 1/2/10；安装关系和所有正例覆盖仍需评估。
- **i05 的信息遗漏值得验证。** NLLB 丢失“接线”，Base / So400m 英文 AP 分别从 0.8711 / 1.0000 降至 0.7644 / 0.9429。译文遗漏与下降并存，但整句措辞也改变了，需要独立查询上的受控对照才能确定影响。
- **i06 的通道/成排关系仍薄弱。** 两译者均没有清楚保留两排柜间通道；OPUS 的不自然句子在两检索模型上英文 AP 都是 1，NLLB 则为 0.3333 / 0.5000，首位均为 e019 单个开柜。中英融合使 NLLB-So400m 恢复首位 e021、AP1，Base 仍首位 e015、AP0.5。不能只按语言流畅度预判图文排序。
- **i07 套管/散热片未解决，融合也会退步。** NLLB 英文 Base AP 0.7548 → 0.8100，So400m 却 0.9267 → 0.8529；Base 融合 0.9267 → 0.7100，首位从露出目标结构的 e029 换为 e024 封闭外罩负例。heat sink / tube 仍不足以证明模型会检索可见 bushing / fins。
- **i08 一般改写也会影响覆盖。** 两译者都保留 UPS 和电脑/服务器用途，NLLB 英文 AP 仍下降；So400m 为 1 → 0.8426。术语表只覆盖三个领域词，不能代替整句信息保真与最终检索评估。

原样翻译、逐意图正例位置、Top5 和指标保存在[数值摘要](../benchmarks/stronger-translation-v1/results-summary.json)。本机可查看 `artifacts/stronger-translation/review.html`，同屏对比四组合的原样英文与三策略 Top5，包含每张图的来源/许可。该页的 policy p50 是整种策略的分位数，不是该意图专属耗时。

## 下一步改进，保持不训练

1. **默认仍用 OPUS，保留 NLLB 可选路径。** 这个小集支持把 OPUS + So400m 自动英文作为完整排序质量的候选，重视首位时保留自动融合。Base 需要速度时继续作基线。先在独立现场图/查询验证，再更换实际默认行为；没有按这 8 条训练或调整融合权重。
2. **由领域人员审核术语与结构。** 重点确认 transformer bushing、可见 cooling fins / radiator fins，以及 open/closed casing、visible wiring、under/behind panels、between rows of cabinets。术语约束与额外预训练译者只能在新开发集确定后，用留出集评价，不能修正本集输出后当作原实验。
3. **扩充真实查询和困难负例。** 同时包含同类不同外壳、裸露套管/鳍片与百叶外罩、单柜/成排通道、板下/无板逆变器；按物理设备分组。现有助手标签先做人工复核，纠正时另建版本。
4. **测服务成本与资源。** 当前 NLLB 体积、加载和首次请求成本更高；未来多轮交错顺序，记录峰值内存、并发、真实查询长度和队列延迟。量化/不同解码配置另作实验，当前结果不能证明它们的收益。
5. **缓存单独评价。** 若加翻译缓存，分别测 miss/hit，键包含原中文、译者 checkpoint、生成设置、语言控制与处理版本；使用真实命中率，不能用固定 8 条的重复命中冒充普通请求速度。
