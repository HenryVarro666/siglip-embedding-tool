在同6条主失败意图上，回退结果与本次原始OPUS或中文控制完全一致；在同10条接受意图上，回退策略继续使用约束结果。完整排名/分数和两阶段轨迹全部与应选控制一致，重复/分支排名分歧为0、分数最大漂移0。
