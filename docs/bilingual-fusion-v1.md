# 中英文查询融合与三条中文退步分析（2026-10-31）

固定40张图库与8对中英文意图，分别比较中文单独、英文单独和等权分数融合。**没有训练，没有改图片/查询/标签，没有按单条查询调权重。** 本轮沿用现成的配对英文查询；翻译或生成英文的耗时不在测量内。

在这个试验集上，Base中文mAP **0.587 → 融合0.812**；So400m中文mAP **0.690 → 融合0.942**。融合p50分别约 **8.60 / 30.10ms**。So400m英文单独mAP为**0.958**，高于融合，且耗时更低；Base融合在i04/i07的AP低于其中文基线。

## 三条查询为什么退步

这里的“退步”指上一轮Base→So400m的中文AP下降。它们不是同一种问题，也不表示全部指标同时下降。以下是完整排名、同查询正负例分差与原图核对得到的观察；关于内部机制的说法保留为待验证假设。

### i04：光伏板下方/背面安装

中文：`安装在光伏板下方或背面的太阳能逆变器。` AP **0.557576 → 0.476190**。So400m将[e014](https://commons.wikimedia.org/wiki/File:Vermont_Law_School_Solar_Panel_Array-4.JPG)黄色墙挂逆变器从第8提到第1，但图中没有可见光伏板；真正板下逆变器[e006](https://commons.wikimedia.org/wiki/File:M%C3%BCllberg_Speyer_-_2.JPG)从第1变成第2，两者在So400m中的分差仅约0.00117。设备类别/黄色机壳相似，安装空间关系未稳定约束住首位。

同时，中央逆变器e002由11→7，多台板下逆变器e010由5→4，Recall@10从2/3提高到3/3；这条是首位与AP下降、深处覆盖改善。不能写成“召回全面下降”。纯光伏板背景也被压低，错误更集中于逆变器类别内部的关系区分。

英文对应查询在So400m中AP为0.809524，同一图库能够得到正确的安装场景排序。可检验的解释是中文“下方/背面”与类别线索的组合不够稳定；e014上可见的光伏相关文字也可能竞争语义线索。要确认具体机制，需要固定分辨率的对照、关系词改写或遮字实验。

### i05：打开的配电/控制柜、可见接线

中文：`打开柜门后能看到接线的电气配电柜或控制柜。` AP **0.683333 → 0.610909**。首位[e015](https://commons.wikimedia.org/wiki/File:BMA_Automation_Allen_Bradley_PLC_4.JPG)始终正确，主要损失是有明确开门与配线的[e018](https://commons.wikimedia.org/wiki/File:Amazingly_wired_fuse_box_in_sauna.JPG)从第4跌到第11；闭合UPS柜[e031](https://commons.wikimedia.org/wiki/File:EPS_6000_Row_B.jpg)从第6升到第2。其他开柜正例e017/e022反而改善，故应检查“柜体类别+内部接线/开门”联合条件，而非笼统说模型看不懂柜子。

英文两模型AP都为1.0；So400m将全部5张正例排在前5。e018对e031的中文分差由+0.00407变为-0.03478，So400m英文分差却为+0.05784。构图、文字表达和图文对齐存在交互的证据较强，尚不能归因到某个中文词或仅归因于背景。

中文强调“打开柜门后”，标注接受门扇不入镜但内部裸露的近裁图。这是需人工复核的措辞边界；主要受损的e018本身有清楚柜门，边界不足以解释全部下降。

### i07：室外变压器、可见套管或散热片

中文：`能看到套管或散热片的室外电力变压器。` AP **0.778333 → 0.523290**，为三条中下降最多。首位仍正确，但[e027](https://commons.wikimedia.org/wiki/File:Fenced_transformer.jpg)从1→6、[e026](https://commons.wikimedia.org/wiki/File:Electrical_transformers_for_Jons_Supermarket.jpg)从2→10，Recall@5由3/5降到1/5。非变压器的逆变站[e013](https://commons.wikimedia.org/wiki/File:Suzu_Photovoltaic_Power_Station_Inverter.jpg)从29→3，配电内景[e019](https://commons.wikimedia.org/wiki/File:Hauptverteiler200_A.jpg)从11→4。

e023/e024虽然来源确认为变压器，照片只见外罩/百叶，按照冻结的“可见套管或散热片”条件属于困难负例。其高排反映设备大类与细部属性的混淆；e013/e019的前移说明错误还超出了百叶/散热片外观相似。

So400m英文AP为0.876667，5个正例在1/2/4/5/6名。同一套So400m图像向量保持不变，换成英文查询后的差异支持中文技术词及组合条件参与排序问题；“套管”的多义性、近景圆筒变压器偏好和复杂背景是候选解释。尚不能据这3条认定中文训练数据不足或384分辨率导致退步。

### 排除长度问题与因果边界

这3条中文输入在两个checkpoint中分别为16/18/15tokens，英文为11/12/12，均低于模型64token上限；编码器也会拒绝超长输入。因此没有查询截断导致退步的证据。完整分差、AP贡献分解和语义边界见[诊断数据](../benchmarks/bilingual-fusion-v1/regression-diagnosis.json)。

Base与So400m的图像/文本分支、容量和原生224/384分辨率同时变化。英文对照与融合能验证可用的改进方式，无法独立定位某个分支或训练来源的根因。

## 固定融合方法

每个模型在自己的匹配向量空间内，对现有中英文查询分别编码为归一化向量，取两个余弦相似度的平均：

\[s_{mix}(I,q)=0.5\,\hat v_I^\top\hat t_{zh}+0.5\,\hat v_I^\top\hat t_{en}.\]

实现把归一化查询向量按权重平均，直接与单位图库向量点积，保留平均余弦的数值。融合时两条文字组成batch2；单语言batch1。权重在运行前固定为0.5/0.5，没有用这3条或8个意图选择不同权重。

## 计时口径与验证

- M4 Pro / 24GiB统一内存 / MPS / float32。各自复用原生224/384生成的冻结图库索引。本轮没有重新编码图库；索引读盘和模型构造/加载单列在JSON汇总中。
- Base与So400m在独立进程中顺序运行。每种策略预热3次；8个意图各重复10次，即每策略80次、每模型240次、总480次。每轮每意图轮转三种策略执行顺序，前后同步MPS。
- p50/p95包含分词、文字编码、CPU向量搬运、身份核对、分数融合和完整40图排序。排除模型加载、原图/权重下载、图库建库、英文翻译/生成和文件报告写入。英文文本已经由原始冻结配对给出。
- 使用批量双文本编码的融合计时，不是将两个单查询耗时相加；实际CPU/API/输入长度和batch对性能均有影响。
- 两模型各16条历史单语言完整排序全量一致；最大分数差2.98e-8。各策略10轮全部排名一致，最大重复分数差0，低于预先固定1e-5容差。数据/协议/代码/两索引哈希均与freeze一致。
- 独立复算48条完整40图排序、480个计时样本和全部比较项。186项离线测试通过，保留备用训练代码，全程不训练。

## 使用与复现

直接用已有索引执行等权中英查询：

```bash
uv run siglip-tools search-text \
  --index artifacts/equipment-benchmark/quality-v1/index.npz \
  --query "能看到套管或散热片的室外电力变压器。" \
  --english-query "An outdoor power transformer with visible bushings or cooling fins." \
  --top-k 5 --device mps --local-files-only
```

Python API：

```python
from siglip_tools.fusion import search_texts

# encoder / index来自同一模型与processor身份。
matches = search_texts(index, encoder, [chinese_query, english_query], top_k=5)
```

完整实验命令、协议与结果汇总见[本轮评估目录](../benchmarks/bilingual-fusion-v1/README.md)。本地对比页为`artifacts/bilingual-fusion/review.html`，可展开8个意图，查看两模型/三策略Top5及逐图来源。

## 保存的改进点与边界

1. **保留英文控制组和按意图评估。** 等权融合优于中文平均分，仍可能低于英文或损伤个别中文强项。下一轮使用独立人工审核留出集比较固定融合、英文单独和规则选择；当前不按这8条调权重或为失败项特设权重。
2. **核查英文的可获得性。** 当前英文是人为编写且与标签意图对齐。若部署只有中文输入，应单独测自动翻译/术语表、翻译缓存及端到端耗时；这次不能替它给出效果和延迟承诺。
3. **定位关系/属性混淆。** i04做“下方/背面/后面”的固定改写和安装关系对照；i05区分裸露内部与完整柜门；i07区分套管、散热器片、外罩百叶及普通管件。改写或区域遮挡应作为新版本实验保存，不回改v1真值。
4. **避免把跨模型分数当统一置信度。** 文中分差只在同一模型、同一查询中解读；融合只混合同一模型的两种语言分数。后续若研究权重或置信度，应在开发集确定，再到未用于诊断的查询上评估。
5. **保留现场数据和人工审核优先。** 当前40张公开图片可能与预训练来源重叠，8个意图不足以推导稳定显著性。标签、查询和分析来自助手，仍需人类与真实场景复核。先扩充独立评估和廉价查询策略，再决定是否需要局部特征或训练。

默认单查询行为与默认Base模型保持原样，等权融合通过`--english-query`显式启用。此次结论只针对这一小规模试验集。
