# SigLIP 2 设备检索小规模评估（2026-10-31）

在冻结的40张图库、16条中英文查询上，So400m384的Hit@1为**14/16（87.50%）**，Base224为**11/16（68.75%）**；mAP从0.693提高到0.824。本机常驻查询p50从6.84ms增加到21.29ms，约3.11倍。部分中文查询退步，因此这是小样本配置选择依据，不是一般精度保证。

**本轮只做预训练推理，没有训练。** 查询是助手根据图库类别/属性编写；相关性由两位助手目视及来源核对，未经过独立人类审核。16条只是8个意图的中英文版本。

## 数据与复现

- 40张：13张太阳能逆变器（含1张站房远景）、1张MPPT充电控制器、8张配电/控制设备、7张变压器、6张UPS、5张光伏板背景。来自Wikimedia Commons；[逐图来源与署名](../benchmarks/equipment-v1/ATTRIBUTION.md)保存作者及CC BY/BY-SA/CC0许可。来源许可和缩略版本按[Commons复用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)保留。
- 下载约13.44MB；没有本地裁剪或重压缩。源文件SHA-1、规范化像素SHA-256无重复；64位dHash距离<=8无候选。目视未见明显同照片近重复；不能保证不同实物或完全去除近重复。
- [查询与全部正例](../benchmarks/equipment-v1/README.md)、[标注规则与纠正记录](../benchmarks/equipment-v1/annotation-notes.json)、[第二助手盲审矩阵](../benchmarks/equipment-v1/label-review.json)、[冻结记录](../benchmarks/equipment-v1/freeze.json)。每条有1–6张相关图；不是单一正确答案分类。
- 标签/清单/查询在目标模型运行前冻结于`5132bda`。第一次Base尝试在结果JSON序列化时失败，未保存或查看排序；修复SizeDict转换并补回归测试后，在`ee8b2fe`下重新运行两套模型。标签和图片哈希全程未改，失败尝试不纳入结果。
- 两个独立进程依次执行，M4 Pro、24GiB统一内存、MPS、float32、图片batch4、查询batch1。模型保持eval/inference_mode。每个模型文本预热3次，每条查询重复10次，共160次热查询。
- 使用[Base224官方checkpoint](https://huggingface.co/google/siglip2-base-patch16-224)和[So400m384官方checkpoint](https://huggingface.co/google/siglip2-so400m-patch14-384)，各自原生224/384输入。容量和分辨率同时变化，不是隔离容量的消融。

完整可执行命令见[评估集README](../benchmarks/equipment-v1/README.md)，可读汇总见[results-summary.json](../benchmarks/equipment-v1/results-summary.json)。原图片、索引、完整40名排序及每次计时在本机Git忽略目录`data/equipment-v1/`与`artifacts/equipment-benchmark/{base-v1,quality-v1}/`。

## 选择和待解决问题

本轮可保留Base作为轻量/开发配置；优先排序质量时可选择So400m，接受约3.11倍的本机热查询耗时和更慢建库。结果只支持这40张公开图与这8个意图，暂不改动工具的默认模型，也不启动训练。

1. **先补人工审核与真实查询。** 检查严格属性边界和木制安装板等语义边界；若修改标签，建立新版本并对两套模型重新评估，不覆盖v1。收集用户现场照片、真实查询及设备分组，减少公开图库/助手编写查询造成的偏差。
2. **单独检验中文。** 扩展同义改写、空间/安装关系查询；可另测中文→英文或双语融合，但本次未验证翻译/融合方案，不能将英文表现当作该方案已有效。
3. **局部和场景关系。** 针对e014/e006与单柜/通道的混淆，另做主体裁剪、整图+局部重排对照，保留场景上下文，检查是否损伤“板下安装”等关系。
4. **精确型号另建任务。** 本集没有SKU/铭牌真值，不据此判断型号识别；只有真实需求和可读铭牌样本到位后再评估OCR融合。
5. **图片检索、规模和资源独立评估。** 本轮只评价文字搜图；以图搜图需非自身、非重复且设备身份明确的查询图。大图库再测ANN、增量缓存、并发和峰值内存；当前40图的向量排序约0.02–0.03ms，不足以外推生产规模。
6. **保持不训练优先。** 备用训练代码保留。先用固定人工留出集判断预训练+查询/局部特征方案是否不足，再讨论微调。

公开图片可能进入WebLI等预训练来源，无法证明无训练重叠。此次无显著性检验、无独立人类标注、无用户现场留出集；以上结论为试验性观察。
