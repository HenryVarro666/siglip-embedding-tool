# Project guidance

- The default workflow is pretrained inference. Never start training just because backup training code exists.
- Read README.md for install and commands. Use `uv sync --frozen --extra dev --extra translation` for the full suite and Python 3.12. Base retrieval alone does not require the translation extra.
- Run the full offline suite with `uv run pytest -m 'not integration'`; lint with `uv run ruff check src tests training examples`.
- Real-model tests are opt-in with `SIGLIP_RUN_MODEL_TESTS=1`, require the pinned default model cached locally, and do inference only.
- Preserve the original learning notes, conversation archive, loss demo and original tests.
- Model and processor revision, preprocessing and runtime identity travel with every index. Never bypass compatibility checks just because dimensions match.
- Keep raw images, weights, local indexes and local results out of Git. The repository is private by default.
- The two existing inverter photos are smoke-test references, not a retrieval benchmark. Filenames are not evidence of an exact SKU or physical object identity.
- Equipment pilot inputs live in benchmarks/equipment-v1; images live in ignored data/equipment-v1. Freeze queries/qrels before either model run and preserve result hashes. AI-assisted relevance labels are not human-audited truth. A corrected label set requires a new version and reevaluation of both models.
- Bilingual experiment inputs live in benchmarks/bilingual-fusion-v1. Published comparisons use eight intent-level rankings per policy, fixed equal cosine weights and supplied English pairs. Keep English-only as a control; translation time is excluded. Preserve previous experiment reports, reject score/rank drift, and do not tune per-query weights on this pilot.
- Automatic translation experiment lives in benchmarks/auto-translation-v1. Its auto_en/auto_fusion timings include a fresh OPUS-MT translation every request. Keep generated English verbatim, validate translator provenance and all artifacts, include translation in directly measured totals, and list loading/first request separately. Previous supplied-English timings exclude translation and must remain clearly distinguished.
- Stronger-translation comparison lives in benchmarks/stronger-translation-v1. Keep both pinned OPUS-MT and NLLB-200 1.3B, fresh translation per request, separate Base/So400m indexes, the predeclared terminology rubric and original English outputs. NLLB requires zho_Hans source control and eng_Latn target BOS; record these differences. Use fresh OPUS controls for timing comparisons. Terminology review is assistant-only and completed without seeing retrieval rankings; it is not human ground truth. Preserve the NLLB CC-BY-NC-4.0 provenance and keep weights local.
- Record limitations and future work in docs/improvements.md. Do not silently expand into OCR, a web service or 3D geometry generation.
- Start continuation work at docs/README.md and docs/continuation.md. The user requires past, current and future encountered problems and improvements to persist in repository documents, not only chat. docs/issue-log.md owns active stable issue IDs; docs/historical-issues.md backfills SIG-001–019. At discovery add status, evidence, impact and next action; after a fix add the actual change, tests/results and remaining limits. Record failed attempts and excluded timing runs with reasons. Keep old reports and negative results.
- At every handoff update docs/continuation.md with completed work, exact revisions/protocol/output paths, outstanding issues and next commands; link any new report from docs/README.md and docs/improvements.md. Do not label proposed work as completed, or replace a measured result with a later improvement.
- Terminology-constraint experiment lives in benchmarks/terminology-constraints-v1. Its glossary and context rubric were frozen before the new queries. Compare original beam1, ordinary beam4 and constrained beam4, with fresh translation and the same fixed 0.5/0.5 fusion. Keep generated English unedited; lexical coverage does not prove wiring, negation or mounting relationships were preserved. Score failed intents as zero in the unconditional metric denominator and separately report failure cost/rate.
- The constrained decoder source is prepared locally at pinned revision07b2f120b7db38f1d7bac617ad65ea130508f297; only four code/README files are downloaded, not Qwen weights. Do not vendor its undeclared repository-level license source or use a live remote generation string at query time. Preserve file/provenance hashes. New query labels are assistant-only, share the original40-image gallery, and must not be described as independent field data or human gold.
- The full decoder test coverage needs its four pinned source files in the Hugging Face cache (the explicit prepare step fills it; CI does this without model weights). Without that cache22 tests explicitly skip; report skipped coverage rather than treating it as the same319-test validation. A saved local decoder remains sufficient for inference. The after-run exporter is fixed to v1 and must bind the frozen protocol/content, support files, packaged glossary and current core before deriving subsets.
